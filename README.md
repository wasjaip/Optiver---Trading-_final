# Optiver — Trading at the Close

Проект по прогнозированию краткосрочного движения цен акций в последние минуты торговой сессии Nasdaq.

Задача основана на соревновании Kaggle **Optiver — Trading at the Close**.

## Задача

Используя данные стакана заявок и closing auction, спрогнозировать движение цены для набора акций перед закрытием торгов.

## Особенности задачи

- высокочастотные финансовые данные;
- сильная временная зависимость;
- информация из order book и closing auction;
- необходимость аккуратной временной валидации;
- метрика — MAE.

## Стек

`Python` · `pandas` · `NumPy` · `scikit-learn` · `Jupyter` · `time series` · `finance`
